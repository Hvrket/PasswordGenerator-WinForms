# PasswordGenerator-WinForms

Автономное десктопное приложение на платформе .NET для генерации случайных паролей по заданным критериям сложности. Разработано в рамках курсового проекта по модулю ПМ.01 (специальность 09.02.07 «Информационные системы и программирование»).

## Функционал и технические особенности
* **Безопасная генерация:** Вместо стандартного `System.Random` используется криптографически стойкий `RandomNumberGenerator.GetInt32` из пространства `System.Security.Cryptography`, работающий на базе системной энтропии ОС Windows.
* **Оценка стойкости:** Выполняется расчет информационной энтропии Хартли по формуле \(E = L \cdot \log_2(N)\). Реализована цветовая индикация надежности полученной строки.
* **Интерфейс:** Разработан императивным (программным) путем на базе Windows Forms без использования внешних файлов `.resx`. Поддерживает динамический сброс результатов при изменении входных параметров.
* **Работа с буфером обмена:** Внедрено копирование в Clipboard с перехватом исключений `ExternalException` при блокировках WinAPI.

## Технологический стек
* **Язык программирования:** C#
* **Платформа:** .NET 8.0 / 10.0
* **Графическая библиотека:** Windows Forms
* **Среда разработки:** Microsoft Visual Studio 2022

## Структура исходного кода
* `Program.cs` — точка входа в приложение, инициализация жизненного цикла формы.
* `MainForm.cs` — графический интерфейс, программное позиционирование компонентов и обработчики событий.
* `PasswordGenerator.cs` — бизнес-логика приложения, формирование пула символов, циклы генерации и расчет энтропии.
